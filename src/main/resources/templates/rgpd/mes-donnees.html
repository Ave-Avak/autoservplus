Le règlement général sur la protection des données vous donne le droit d'obtenir une copie des données que nous détenons sur vous.

Ce que contient le fichier

  • Votre profil.
  • Vos véhicules.
  • Votre panier en cours.
  • Vos rendez-vous et interventions.
  • Vos commandes.
  • Vos factures.
  • Vos consentements.
  • Vos données de connexion.
  • Les informations sur le traitement.

Ce que le fichier ne contient pas

  • Votre mot de passe.
  • Vos données de carte bancaire.
  • Les jetons de session.

Confirmez votre mot de passe

Votre mot de passe est redemandé pour qu'une session laissée ouverte ne suffise pas à télécharger l'ensemble de vos données.

Un export est possible une fois par 24 heures.
